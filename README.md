# MukushevTanat.github.io

## Использованные промпты

### 1. Добавление изображения грузовика и оформление
- **Промпт:**
  > В index.html добавь под заголовком `<h1>` изображение грузовика на дороге (используй картинку с Unsplash по прямой ссылке, добавь alt="Грузовик компании Танат"). В style.css сделай картинку на всю ширину контента, с закруглёнными углами 12px и мягкой тенью.
- **Промпт / сообщение для коммита:**
  > `git commit -m "Добавил фото грузовика и новые стили"`

### 2. Смена цветовой схемы на тёмно-синюю и карточки списка
- **Промпт:**
  > В style.css поменяй цветовую схему страницы на тёмно-синюю: фон страницы линейный градиент от #0f172a к #1e3a8a, текст белый, заголовок h1 оранжевого цвета #f97316. Пункты списка сделай карточками с полупрозрачным фоном rgba(255,255,255,0.1) и оранжевой левой границей.
- **Промпт / сообщение для коммита:**
  > `git commit -m "Изменил цветовую схему: темно-синий градиент и карточки списка"`

### 3. Подключение шрифта Montserrat и анимация карточек
- **Промпт:**
  > Подключи в `<head>` шрифт Montserrat из Google Fonts (кириллица). В style.css примени его ко всей странице: h1 с жирностью 800 и размером 42px, обычный текст 18px с межстрочным интервалом 1.6. Добавь плавную анимацию при наведении на пункты списка: сдвиг вправо на 8px и лёгкое увеличение тени.
- **Промпт / сообщение для коммита:**
  > `git commit -m "Подключил шрифт Montserrat и добавил анимацию пунктов списка"`
